# Forgeon
A web-based forum application built using Vanilla JavaScript, HTML, and CSS.

## Getting started

1. Clone the repository and go into the backend folder:
   ```bash
   cd Forgeon_Community/BACKEND
   ```
2. Install Node dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file inside `Forgeon_Community/BACKEND` and add your environment values:
   ```env
   MONGO_URI=your_mongodb_connection_string
   
   ```
   - `MONGO_URI` is required by the backend.
  .
1. Start the backend server:
   ```bash
   node server.js
   ```
2. Enjoy forgeon my fellas :)
